# ByteSpin

**Spin. Decide. Discover.**

ByteSpin is a customizable, responsive spin-wheel application designed to make random decisions simple, interactive, and fun.

## Features

- Responsive spin wheel for desktop and mobile
- Accurate pointer-based result selection
- Custom wheel values
- Animated spin experience with confetti
- Spin and win sound effects
- Stop control and configurable spin speed and duration
- Spin counter and spin history
- Clear results and view additional results
- Theme selection with preview and saved preferences
- Share results
- Mobile-friendly settings panel

## Built With

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/muthuraja-tester/Bytespin.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

> The application source files will be added to this repository separately. Update these instructions if the project uses a build tool or a different entry point.

## Project Structure

The repository will be organized around the following areas as the source code is added:

- `assets/` — images, icons, and sound assets
- `css/` — application styles and responsive layouts
- `js/` — wheel logic, settings, history, and storage
- `docs/` — feature documentation and changelog
